A faster drop-in for make.fun's makefun-site 1.0.0: the same static site generator output, byte for byte, at about 4.4x the speed on the practice set. `solve.js` is a dependency-free ES module whose `run(input)` returns exactly makefun-site's answer for every case; `main.ts` is the harness driver that reads each case from `/input/cases.json` and writes `/output/answers.json`.

## Run it

```sh
node main.ts
```
